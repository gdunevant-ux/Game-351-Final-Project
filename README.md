# The Fastest

## Overview
Within this project, we combined our efforts to make a functioning game in Unity. The game includes a competitor car and forces the player to use shortcuts and boosts to win.

## How To Play
- W and Up arrow key: move forward
- A and Left arrow key: move left
- S and Down arrow key: move backward
- D and Right arrow key: move right
- T: toggle camera angle
- B: toggle back camera
- Press Play on the menu screen to play
- Press Quit on the menu screen to quit

## Installation Process
1. Clone the repo:
   ```
   git clone https://github.com/gdunevant-ux/Game-351-Final-Project
   ```
2. Open Unity Hub, click **Add**, and select the cloned project folder.
3. Open with Unity version `[insert version, e.g. 2022.3.x LTS]`.
4. Open the main scene from `Assets/Scenes/`.
5. Press Play to test.
